# 🏗️ מנתח תב"ע AI

ניתוח אוטומטי של מסמכי תכנון ובנייה (תב"ע) והפקת דוח תמהיל דירות מלא.

---

## 📋 דרישות מוקדמות

- Python 3.10 ומעלה
- API Key של Anthropic (מ-console.anthropic.com)

---

## ⚡ הרצה מהירה

### 1. צור סביבה וירטואלית
```bash
python -m venv venv
source venv/bin/activate          # Mac / Linux
venv\Scripts\activate             # Windows
```

### 2. התקן תלויות
```bash
pip install -r requirements.txt
```

### 3. הגדר API Key
צור קובץ `.env` בתיקיית הפרויקט:
```
ANTHROPIC_API_KEY=sk-ant-...
```
או הזן אותו ישירות בממשק האפליקציה.

### 4. הרץ
```bash
streamlit run app.py
```
האפליקציה תיפתח בדפדפן בכתובת: http://localhost:8501

---

## 📁 מבנה הפרויקט

```
taba_analyzer/
├── app.py              # ממשק Streamlit הראשי
├── pdf_processor.py    # חילוץ טקסט מ-PDF + Chunking
├── ai_analyzer.py      # אינטגרציה עם Claude API
├── excel_exporter.py   # יצוא ל-Excel מעוצב
├── requirements.txt    # תלויות Python
└── .env               # (לא מועלה ל-Git) API Key
```

## 🎯 מה האפליקציה מנתחת?

| תחום | פרטים |
|------|--------|
| **זכויות בנייה** | שטח מותר, אחוזי בנייה, קווי בניין, גובה |
| **תמהיל דירות** | כמות ליח"ד, שטחים, אחוזים |
| **חנייה** | חובת חניות לפי שימוש |
| **שימושים מותרים** | מגורים, מסחר, משרדים |
| **הקלות ובונוסים** | תמ"א, בונוסים, הקלות ייחודיות |
| **סיכוני תכנון** | סעיפים עמומים, סיכונים מזוהים |
| **בדיקה מתמטית** | עקביות שטחים, חנייה |
